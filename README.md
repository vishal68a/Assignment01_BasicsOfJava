# Set 1 Programs

## 1. Simple Interest Calculator

### Description
Calculates simple interest based on:
- Account Number
- Customer Name
- Account Status
- Principal Amount
- Rate of Interest
- Time

### Formula

```
Simple Interest = (Principal × Rate × Time) / 100
```

### Concepts Used
- Scanner Class
- Variables
- Arithmetic Operators
- Output Formatting

## 2. Student Report Card Generator (GradingSystem)

### Description

Generates a student's report card by calculating:
- Total Marks
- Average
- Grade
- Pass/Fail Status

### Grade Table

| Average | Grade |
|----------|-------|
| 90-100 | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| Below 60 | F |

### Concepts Used

- Methods
- Conditional Statements
- Scanner
- printf()

# Set 2 Programs

## 1. Sum of Natural Numbers

### Description

Calculates the sum of first **n** natural numbers using a **for loop**.

### Example

Input

```
10
```

Output

```
55
```

### Concepts Used

- for loop
- Scanner
- Variables

---

## 2. Count Digits in a Number

### Description

Counts the number of digits in an integer using a **while loop** inside a user-defined method.

### Features

- Handles negative numbers
- Handles zero
- Uses method `countDigits()`

### Concepts Used

- while loop
- Methods
- Scanner
- Math.abs()
